# 项目交接说明

## 项目定位

后端负责监听 QQ 邮箱中的 Etsy 订单，将订单写入 MySQL，匹配商品与模板，生成示意图/生产文件，并通过 API、SSE 和企业微信向前端及运营人员提供结果。

## 模块与功能

| 模块 | 主要功能 |
| --- | --- |
| `backend/main.py`、`backend/context.py` | FastAPI 应用入口、生命周期管理、全局服务初始化与资源释放。 |
| `backend/api/` | HTTP API 路由，覆盖订单、商品、店铺、模板、配置、任务、系统状态和 SSE 事件。 |
| `backend/database/` | MySQL 连接、事务、表结构检查及数据库访问基础设施。 |
| `backend/orders/` | 订单仓储、状态推进、订单服务、示意图生成、生产文件和客户确认文件处理。示意图发送成功只记录发送标记，订单状态由前端推进。 |
| `backend/catalog/` | 商品、店铺和商品字段解析；根据邮件内容、商品标识及模板规则匹配商品。 |
| `backend/templates/` | 模板仓储、尺寸方案、字体布局、图层规则解析、页数与背脊计算。 |
| `backend/mail/`、`qq_idleCopy.py` | QQ IMAP 长连接/重连、邮件拉取、订单解析和订单生产流程编排。 |
| `backend/notifications/` | 企业微信图片和文本通知。 |
| `backend/events/` | 事件总线及 SSE 订阅，将订单处理进度推送给前端。 |
| `backend/tasks/` | 后台任务注册、执行和状态管理。 |
| `image-map-headless-renderer/` | 使用浏览器渲染 Fabric 图层，导出图片和 SVG，并处理字体、图片资源加载。 |
| `scripts/` | 数据库显式迁移脚本，例如订单示意图发送标记和字体布局作用域迁移。 |
| `tests/` | 订单、模板匹配、尺寸/背脊计算、SSE、通知、文件导出和邮件解析测试。 |

## 模块关联

1. 应用启动时初始化数据库、订单服务、渲染器、任务管理器和邮箱监听器。
2. 邮箱监听器收到新订单后，调用商品/店铺解析器补充订单信息，再交给订单服务。
3. 订单服务通过模板模块选择尺寸方案和字体布局，调用渲染器生成示意图及生产文件。
4. 生成结果写入 MySQL；企业微信模块发送示意图，成功后仅更新 `wecom_preview_sent`，不自动修改订单状态。
5. 订单事件由事件总线发布，SSE 路由推送给前端；前端通过订单 API 显式推进状态。
6. API、邮箱监听和后台任务共享订单仓储与同一套数据库事务边界。

## 部署注意

- 生产环境使用 `.env` 配置 MySQL、OSS、邮箱、企业微信和渲染相关参数，禁止提交敏感值。
- 首次升级到当前版本时，先执行 `scripts/migrate_order_wecom_preview_sent.py`，再重启服务。
- 服务器更新代码后需重启后端服务；日志和运行状态文件不属于源码提交内容。
